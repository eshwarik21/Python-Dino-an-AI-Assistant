# Python-Dino-an-AI-Assistant
https://medium.com/@salisuwy/build-an-ai-assistant-with-wolfram-alpha-and-wikipedia-in-python-d9bc8ac838fe


Python-Dino is an intelligent assistant powered by WolframAlpha and Wikipedia APIs. It processes natural language queries, retrieves answers from WolframAlpha, and falls back to Wikipedia when needed. It also fetches relevant summary content and images to enrich the response.
